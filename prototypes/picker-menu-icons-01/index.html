Picker glyphs: eight renderings

Using the current hp-ico-* sprite in public/index.html (32-unit stroke scenes in a 42px tile) as the base, explore new generations of the hero picker menu icons: different illustration styles, rendering treatments and tile presentations for the room 2x3 and style 2x4 menus.

Same fourteen scenes under every variant; what changes is how they are inked, filled and framed inside the row.

Generated 21 September 2026 · prototypes/picker-menu-icons-01

01

Duotone Line

B+ 89%

The shipped strokes, with every closed shape washed in tint. Weight without a redraw.

  • Two stylesheet rules on the sprite already in production
  • Closed shapes gain mass, open lines stay as detail
  • Inverts on the selected row with one opacity change
  • Stacked shapes wash over each other where they overlap
  • Still monochrome, so wood and linen look alike
  • Tint on tint drops contrast against the hover row
02

Knockout Solid

B 86%

Filled silhouettes with the interior lines cut out in the tile colour, like a stencil.

  • Holds up at half the size, so the tile could shrink
  • No thin strokes to grey out on a 1x display
  • Selected row inverts to a white stencil on navy
  • Open-path details vanish into the fill on dense scenes
  • Knockout colour must track every tile background state
  • Reads heavier next to 14.5px text than the line set
03

Colour Illustration

B 84%

Real material colour per shape: wood, linen, brass, greenery. A picture, not a glyph.

  • Coastal and Farmhouse finally look like different rooms
  • Highest first-glance pull of the eight
  • Colour carries meaning the label cannot
  • A hand-picked palette per shape per scene to maintain
  • Fixed colours cannot invert on the selected navy row
  • Fourteen mini paintings compete with the render behind
  • Needs a colour-blind check on the red barn and green plant
04

Solid Badge

B- 80%

Bold pictograms in a navy badge. Half the tile, twice the stroke, no scenes.

  • Smallest row height, so the style menu stays short
  • Bold strokes survive any display and any zoom
  • Selected row flips to a white badge, unmistakable
  • Back to a pictogram, which is what the brief rejected
  • Style glyphs lose their accessory and blur together
  • Navy badges add fourteen dark blocks to a light menu
05

Draw In

C+ 77%

The line scene, sketched in on hover. Hover a row to watch it draw.

  • Pure CSS on the shipped sprite, no markup change
  • Rewards the hover the picker already invites
  • Makes the detail in each scene visible as it appears
  • Touch never sees it, so phones get the plain line set
  • Must be gated on prefers-reduced-motion
  • Fourteen animations on a fast pointer sweep costs frames
06

Iso Plate

C 74%

Each scene stands in a little room: back wall, floor, a skew for depth.

  • Says "a staged room" without any words
  • Most distinctive tile of the square-ish options
  • Works from the shipped geometry, skew is one transform
  • Sixty-pixel tiles push the style menu wider than the canvas at 1024px
  • Skewed strokes alias visibly on 1x displays
  • Landscape scenes like Coastal make no sense on a wall
07

Big Render

C- 70%

The honest version of the old thumbnail: the real render, at a size that shows something.

  • A true preview, no interpretation between visitor and result
  • Zero drawing to maintain, renders already exist
  • Rooms differ by geometry, styles by palette, both visible
  • Fourteen image decodes per menu open, same as before
  • Popover widens to about 330px and overhangs at 390px
  • A crop still averages out furniture on the darker styles
08

Blueprint Plate

D 62%

The swing: every row is a drafting sheet, grid, code and dimension tick included.

  • Ties the picker to the FAQ floorplan sheet further down the page
  • Most memorable tile of the eight
  • White-on-navy lines invert cleanly for the selected state
  • Triples the row width, the style menu overhangs the frame
  • One-pixel lines on the grid vanish below 1.5x DPR
  • The codes need localising or explaining, and are neither
  • Fourteen mono labels are a second thing to read per row
