Post an incident

Public

Anything you write here appears in Recent incidents on the public status page, in the words you type — the auto-detected entries are the only ones that get translated. The heartbeat only notices the process dying, so this is the way to record an outage the server itself survived: a dead upstream, a bad deploy, an expired key.
